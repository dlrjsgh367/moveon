무브온(MoveOn) Phase 5 구성

무상태 이중화: concert replica 2개 + Traefik 자동 로드밸런싱 (socket-proxy로 Docker provider 활성화)

게이트웨이 + 자동발견

  • • Traefik: file provider(단일 3개) + docker provider(concert)
  • • docker-socket-proxy(nginx)가 API 1.24→1.44 재작성
  • • 그래야 Traefik이 이 데몬(min 1.40)에 붙는다
  • • 외부 개방 :80, accesslog on

concert 무상태 이중화

  • • deploy.replicas: 2 (up 만으로 2대)
  • • 라벨로 Traefik 자동발견 + 라운드로빈
  • • 액티브 헬스체크로 죽은 replica 제거
  • • 상태는 공유 MySQL/Redis에 (그래서 무상태)

데이터 / 이벤트

  • • MySQL 8.4 스키마 4개, 서비스별 분리
  • • Redis Streams reservation-confirmed
  • • 소비자그룹 + XACK + 멱등키
  • • concert→payment는 동기 REST

검증 / 함정

  • • 요청 분배 20회 → 10/10 라운드로빈
  • • replica 1개 kill → 150중 149 200(무중단)
  • • Traefik 버전 업/DOCKER_API_VERSION은 무효
  • • socket-proxy가 이 환경의 유일한 경로
