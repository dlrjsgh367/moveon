무브온(MoveOn) Phase 2 구성

MSA 뼈대 (이중화 없음): 게이트웨이 + 서비스 4개 + 단일 MySQL / Redis

게이트웨이 / 라우팅

  • • Traefik v3.1, 파일 provider
  • • 경로별 라우팅: /concerts, /auth, /payment, /notification
  • • 외부 개방은 80 포트만
  • • 대시보드 127.0.0.1:8080 (서버 로컬만)

앱 서비스 4개

  • • concert: GET /concerts + /health
  • • auth-member / payment / notification: /health
  • • Spring Boot 3.3.4 / Java 21
  • • 멀티스테이지 arm64 이미지

데이터 저장소

  • • MySQL 8.4, 스키마 4개 (서비스별 분리)
  • • 각 서비스는 자기 스키마만 접근
  • • Redis 7: 다음 Phase Streams용 (기동만)
  • • MySQL/Redis 포트 외부 비공개
