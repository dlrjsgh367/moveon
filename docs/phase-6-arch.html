무브온(MoveOn) Phase 6 구성

Stateful HA: MySQL Group Replication 3노드 + ProxySQL 자동 페일오버 (arm64 네이티브)

ProxySQL (라우터 역할)

  • • :3306 단일 쓰기 문 (앱 JDBC 그대로)
  • • GR 상태 읽어 PRIMARY를 writer 그룹으로
  • • 페일오버 시 새 PRIMARY로 자동 전환
  • • arm64 네이티브 (MySQL Router 대체)

MySQL Group Replication

  • • 3노드, GTID + 단일 PRIMARY 모드
  • • 과반(2)이 살아야 쓰기 가능
  • • SECONDARY는 super_read_only
  • • mysql:8.4 GR 플러그인 내장(수동 구성)

페일오버 검증

  • • PRIMARY(mysql-1) kill → mysql-3 승격
  • • ProxySQL writer 자동 전환
  • • 쓰기 50건 중 49 성공(순간 1건만 실패)
  • • 재합류 후 3노드 데이터 일치

함정 / 결정

  • • GR 옵션 loose- 접두어(init 통과)
  • • 조인 노드 GTID 리셋 후 합류
  • • caching_sha2: get_public_key=ON
  • • Oracle mysqlsh/Router amd64 전용 → 회피
